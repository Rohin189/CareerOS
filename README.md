# CareerOS

An intelligent career development platform for software engineers.
Analyzes where you are, where you want to go, identifies the gap, and tells you what to do next.

## Phases

- **Phase 0** — Project scaffolding & git setup
- **Phase 1** — Foundation: React + Node/Express + MongoDB + JWT auth + profile + dashboard
- **Phase 2** — Career dashboard: skill matrix, progress tracking, charts
- **Phase 3** — GitHub integration: repo/commit/language analysis
- **Phase 4** — Job intelligence: job description parsing + skill-gap comparison
- **Phase 5** — Intelligence layer: resume parsing, AI-generated roadmaps
- **Phase 6** — Interview simulator: generated mock interviews + performance feedback loop

## Tech Stack

- Frontend: React (Vite)
- Backend: Node.js + Express
- Database: MongoDB
- Auth: JWT
